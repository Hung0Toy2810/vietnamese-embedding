# Historical web prototype verification — October 20, 2026

The former local UI used three resizable white/blue panels with a 1–2–2 desktop ratio. Nineteen unit/integration tests covered PDF upload/deduplication, invalid files, inline viewing, background tasks, document isolation and evidence mapping.

A real encoder indexing test used two temporary PDFs. A recorded live question about legitimate defense returned Article 22 with a PDF-page citation. This was a smoke check rather than a quality benchmark.

Browser interaction was not visually verified. Scanned PDF OCR was not supported in that prototype, and page-based parents could split cross-page clauses. These are historical limitations; the current semantic implementation is documented separately.
