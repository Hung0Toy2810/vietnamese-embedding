# Historical abstention checks — October 20, 2026

The old law-specific pipeline was tested on two questions not answered by the available criminal-code sources: the deadline for handling a crime report and the minimum night-overtime pay percentage. Both returned an unsupported result without inventing days or percentages. Recorded runs took approximately 148 and 142 seconds.

The questions informed prompt development and therefore were functional examples, not a held-out accuracy benchmark. Matching words in unrelated articles was not accepted as sufficient support. Absence from the supplied sources was not interpreted as absence from the law.

The original code validated source/passages, quotes and citations, with checks shared between generated and verbatim modes. At that historical stage it could append missing source labels from validated evidence. The current pipeline instead requires matching citations explicitly. See the original record for the complete control question and settings.
